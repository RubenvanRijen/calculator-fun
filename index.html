    Store the displayed value under a letter, then use it in any expression. The letters are uppercase, so that "Asin(30)" is A×sin(30) rather than asin(30). E and X are not offered: they already mean Euler's constant and the graph variable.

      Keyboard: digits, + - * / ^ ( ) %, Enter to equal, Backspace to undo a keypress, Esc to clear, ←→ to move the caret, ↑↓ for past entries.
      2nd reaches the alternate on keys that show one: sin/cos/tan → their inverses, log → 10ˣ, ln → eˣ, √ → abs, π → e, MC → clear history, ÷ → nCr, * → nPr, % → n!, Ans → rand, n/d → F⇔D. mode cycles RAD → GRAD → DEG.
